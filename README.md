# Форматировщик JSON и JSONL

Все данные обрабатываются в браузере, без аккаунтов, облачных запросов или отправки содержимого на сервер. Интернет для обработки не требуется. Ссылки содержат сжатый документ в адресе; передавайте их только тем, кому можно читать данные.

## Локальный запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Откройте http://localhost:8080. Установка зависимостей требует интернета, последующая обработка — нет.

## GitHub Pages

1. Загрузите исходники в репозиторий GitHub, в ветку `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Запустите **Deploy GitHub Pages** во вкладке **Actions** или отправьте изменения в `main`.

Публикация автоматизирована в `.github/workflows/pages.yml`. Сайт работает и в корне домена, и по адресу `https://имя.github.io/репозиторий/`. Секреты и облачные переменные окружения не нужны.

## Форматы

- **Авто**: JSON, JSONL или объекты/массивы JSON внутри текста, включая блоки Markdown. Окружающий текст не попадает в результат. Несколько найденных документов объединяются в массив в исходном порядке.
- **JSON**: строгая проверка единственного документа.
- **JSONL**: отдельный JSON на каждой непустой строке. Ошибка в строке блокирует результат, чтобы не терять записи.
- Вкладка **JSONL** сохраняет по одной компактной записи на строку; корневой массив JSON преобразуется в записи по его элементам.

Форматирование и JSONL сохраняют точное написание чисел, включая большие целые. Исходный текст остаётся в левом редакторе. Кнопка удаления текста заменяет его очищенным JSON.
